# GTM Club skills

A growing, open collection of [Claude](https://claude.com/claude-code) skills for
go-to-market: outbound, copywriting, RevOps, pipeline, research and more. Built by
operators, given away for free.

Each folder is one skill in the standard `SKILL.md` format. Drop one into Claude
and it just works.

## Use a skill

Browse the folders above, or clone the whole set:

```bash
git clone https://github.com/vicfromthegtmclub/gtmskills.git
```

Then point Claude at the `SKILL.md` you want. Claude Code, the desktop app and the
API all read the same format.

## Browse them with search

Every skill is also on the site, searchable and filterable, with interactive tools
alongside: **[thegtmclub.com/library](https://www.thegtmclub.com/library/)**.

## Contribute

Made a skill other operators would use? Submit it at
[thegtmclub.com/submit](https://www.thegtmclub.com/submit/). Good ones land here,
credited to you.

## Star it

If any of these save you time, a star helps other operators find them.
